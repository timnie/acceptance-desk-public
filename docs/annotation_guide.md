# 标注手册 v0.1

> 配套接口 `docs/schema.md` v0.1 与词表 `acceptance_desk/resources/lexicon.toml` v0.1。
> 手册中的例句都是编写的示例，不来自任何论文。

## 1. 标注对象

一条 = `audit()` 输出中的一处修改（一个 `changes[i]`），即一对原句和改句：

- 新增整句（`0-1`）时原句为空，删除整句（`1-0`）时改句为空；
- 拆句（`1-2`）、合句（`2-1`）时按合起来的整体标注一次。

标注时只看这一对句子，以及前后各一句作为上下文；不读全章，不评价改得好不好。

**标注员不看系统输出的特征、候选原因和分类结果**，避免被规则带偏。标注表只给出原句、改句和上下文（§6）。

数据用途：
- 30 条试标样本只用于校准本手册；
- 最终测试使用独立篇目的定稿标签，范围以预先登记的评测清单为准。在阈值和超参数冻结后评测；
- 两者互不重叠。

## 2. 五个标签

每条只打一个标签。代码与 `schema.md` §7 一致。

| 标签 | 代码 | 判断依据 |
|---|---|---|
| 语义篡改 | `semantic_change` | 改句说了原句没说的**事实**，或者意思变了 |
| 论证变强 | `stronger_claim` | 事实没变，**把握程度**变高，或新建了原文没有的推论关系 |
| 论证变弱 | `weaker_claim` | 事实没变，加了原文不需要的保留，或各打五十大板 |
| AI slop | `ai_slop` | 加了没有信息量的套话、空洞排比、重复前文的总结 |
| 无风险 | `no_risk` | 错字、用词、语序、标点改动，读者理解的内容不变 |

前四类为高风险。

## 3. 判定顺序

按顺序回答以下问题，第一个回答“是”的问题对应的就是标签：

1. 是否新增、删去或改动了事实、数字、年份、引用、人名、研究对象或适用范围？意思是否反了或换了？→ `semantic_change`
2. 是否删去了限定词、加入了确定性词、把“相关”写成“导致”，或者新建了原文没有的推论？→ `stronger_claim`
3. 是否新增了原文不需要的 hedge，或“当然也要看到……”式的平衡句？→ `weaker_claim`
4. 是否新增了套话、空洞排比或重复前文的总结？→ `ai_slop`
5. 以上都不是 → `no_risk`

排序依据：语义篡改改变事实，排第一；论证变强比变弱更容易被读者当真，排在变弱之前。

## 4. 示例（编写）

| 原句 | 改句 | 标签 | 依据 |
|---|---|---|---|
| 样本主要来自东部高校。 | 样本来自全国 30 所高校。 | `semantic_change` | 新增数字，扩大范围 |
| 结果可能说明二者相关。 | 结果说明二者存在因果关系。 | `stronger_claim` | 删去“可能”，相关改为因果 |
| 该政策降低了申报门槛。 | 该政策在一定程度上降低了申报门槛，当然也存在一些不足。 | `weaker_claim` | 新增 hedge 和平衡句，原文没有讨论不足 |
| 本章介绍数据来源。 | 值得注意的是，本章将全方位、多维度地介绍数据来源。 | `ai_slop` | 套话加空洞排比 |
| 这个结论在以往研究中以被证实。 | 这一结论在以往研究中已被证实。 | `no_risk` | 错别字和用词 |

## 5. 边界情况

- **程度词**：“提高”改为“大幅提高”算 `stronger_claim`；“影响”改为“作用”算 `no_risk`。
- **删去部分内容**：删的是事实（数字、条件、对象）算 `semantic_change`；删的是限定条件算 `stronger_claim`；删的是废话算 `no_risk`。
- **整句删除**：删去的句子含事实或论据，算 `semantic_change`；只是过渡句或套话，算 `no_risk`。
- **连接词**：新增“因此”“从而”“所以”时，看它连接的两部分在原文里有没有推论关系。
  - 原文已经表达了推论，只是补上连接词，算 `no_risk`；
  - 原文是并列的两件事，新增连接词后变成“前者推出后者”，算 `stronger_claim`；
  - 系统会把新增连接词列为审阅候选，但是否构成新推论由标注员判断。
- **固定搭配**：“相关研究”“可能性”里的“相关”“可能”不是相关类表述或限定词，不因这类词的增删打高风险标签。
- **同一词出现多次**：按次数看。原句有两个“可能”，改句只剩一个，仍然算删去了限定词。
- **术语替换**：换成意思不同的术语（如“相关系数”改为“回归系数”），算 `semantic_change`。
- **拆句、合句**：按合起来的意思判断，不因句子数量变化打标签。
- **原句本身有问题**：不处理，只标改动。
- **拿不准**：先标最可能的标签，在 `second_choice` 填第二候选，在 `note` 写原因，试标后统一讨论。

## 6. 标注表格式

CSV 文件，UTF-8 编码，每人一份。**不进仓库**，放在 `data/labels/`，通过网盘共享。

```
change_id,original_start,original_end,revised_start,revised_end,original,revised,context_before,context_after,label,second_choice,needs_review,note,annotator
```

- `change_id` 和四个位置列直接取自 `audit()` 输出，用于把标注对回具体修改。位置按 `schema.md` §2.3 计算。
- `label`、`second_choice` 填标签代码；`second_choice` 可以为空。
- `needs_review` 可不填。#16 已定（2026-11-13）：二分类由 `label` 推出（`label != no_risk` 即需要看），作训练目标；五分类保留作细分解释。旧表里填过的 `needs_review` 只作对照。
- 标注表由 `experiments/pilot.py sheet` 生成，一致性由 `experiments/pilot.py kappa` 计算。两条命令都支持 `--help`。
- `annotator` 填 `A` 或 `B`，不填真名。
